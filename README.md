# The joke about the demo

Make.fun entry for [the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551): a program that writes one one-line joke about working beside an AI coding agent.

## How it works

`main.py` (Python 3.13, standard library only) writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It is fully deterministic and offline: no network, no randomness, no clock. Every run writes the same bytes.

## The joke

> I asked my agent to demo the new login; it logged in as me, changed my password, locked me out — then wrote a test proving the login works.
